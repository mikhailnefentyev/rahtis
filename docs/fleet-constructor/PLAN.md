# Конструктор сцепок — план (28.10.2026)

## Решение пользователя

Цитата: «чтобы не путаться — регистрируем отдельно тягачи, микроавтобусы, грузовики, самосвалы (нуппи), полуприцепы (самосвал, тент, изотерм, реф, трал), прицепы (самосвал, тент, реф, изотерм, трал); тент, реф, изотерм — с выбором загрузки сверху, сбоку, сзади. Перевозчик сам вносит грузоподъёмность, габариты, оси и как на конструкторе собирает сцепку для заказа».

Примеры сцепок:
- тягач один — для перецепки клиентских прицепов;
- тягач + самосвальный PPV;
- нуппи + прицеп (самосвал, тент, реф, изотерм, трал), например нуппи + трал для трактора на стройке;
- грузовик 3 оси + прицеп (тент, изотерм) — для большего объёма.

Ещё два решения:
- **Сцепка собирается под заказ.** В кабинете сохранено несколько сцепок. Откликаясь на заказ, перевозчик выбирает сцепку. Одна машина может входить в несколько сцепок.
- Кузов PPV у sora-auto (ветка 28.10) отменён: PPV — это полуприцеп к тягачу. Миграции `20261028210000_body_ppv_enum` и `20261028210100_sora_auto` не применены, лежат вне папки миграций (scratchpad/parked). Из них берём привязку прицепа и названия nuppi, kasetti, puolikas.

## Этап A — карточки и конструктор (кабинет)

**Машины.** Типы: TRACTOR (тягач), VAN (микроавтобус), TRUCK (грузовик), TIPPER (нуппи, самосвал 3–5 осей).
- У TRUCK и TIPPER есть кузов.
- У TRUCK — загрузка (сверху, сбоку, сзади) и внутренние размеры.

**Прицепы.**
- Вид: SEMI (полуприцеп), FULL (прицеп), CENTER_AXLE (прицеп с центральной осью).
- Кузов: TIPPER (самосвал), CURTAIN (тент), ISOTHERM (изотерм), REEFER (реф), LOWBED (трал) и прежние.
- Загрузка: TOP, SIDE, REAR.
- Своя грузоподъёмность, внутренние длина, ширина и высота, погрузочные метры, объём, оси, масса, тара, до сцепки, длина.
- Пометки полуприцепа: MEGA, LIFTING_ROOF.

**Сцепки (`vehicle_combos`).**
- Поля: компания, машина, прицеп (или пусто), название.
- Расчёт хранится в строке, считает сервер через mass.ts: законный предел по SKAL, грузоподъёмность, погрузочные метры, объём, кузова и загрузка.
- Правила: полуприцеп — только к тягачу; прицеп — к грузовику или нуппи; к фургону — ничего; тягач без прицепа — только для перецепки.
- Названия сцепок нуппи: «Nuppi», «Kasetti» (нуппи + прицеп), «Puolikas» (тягач + самосвальный полуприцеп).

**Права.** Новым колонкам выдавать и `grant insert`, и `grant update` (см. память rahtis-column-grants).

## Этап B — заказы по сцепкам

**Требования заказа:**
- кузов (тент, реф, изотерм, трал, самосвал или любой);
- загрузка (сверху, сбоку, сзади);
- MEGA;
- погрузочные метры, вес, объём.

**Отклик и назначение — сцепкой:**
- `order_offers.trailer_id`, `orders.assigned_trailer_id`;
- `take_order(order, vehicle, trailer)`;
- `vehicle_fits_haul` с прицепом.

**Подбор по сцепке:**
- перецепка и контейнер — тягач один;
- экспресс (фургон, грузовик, фура) — метры, вес, кузов и загрузка сцепки;
- стройка — нуппи, кассета или puolikas.

**Остальное:**
- у водителя виден прицеп рейса;
- на столе показаны требования заказа.
