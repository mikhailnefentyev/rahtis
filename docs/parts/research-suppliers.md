## 2. Inter Cars IC API — детали [проверено по docs.webapi.intercars.eu]

- Документация: https://docs.webapi.intercars.eu/ic-api/en/docs/documentation/Intro, контракт: https://docs.webapi.intercars.eu/ic-api/en/contracts/api
- REST, базовый URL `https://api.webapi.intercars.eu/ic/…`. Нужен отдельный клиентский аккаунт; Inter Cars по e-mail выдаёт ClientID/ClientSecret для sandbox и prod + доступ в DevPortal (там «Try out»: генерация токена). Схема — по токену из client id/secret (похоже на OAuth2 client credentials, явно не названо).
- Для «крупных клиентов, продающих из своего магазина/ERP». Перед продом — приёмочные тесты в тестовой среде с IC. Лимиты (почасовые/суточные), троттлинг при частых опросах склада.
- Эндпоинты: `GET/POST /ic/inventory/stock` (до 100 SKU: наличие по складам, крайняя дата доставки, время отсечки заказа), `POST /ic/inventory/quote` и `POST /ic/pricing/quote` (прайс и цена клиента нетто/брутто, НДС), `GET /ic/catalog/products` (SKU, бренд, TecDoc ID, EAN; фильтры только category/sku/index/brands), `sales/requisition` (заказ), delivery, invoice, customer.
- **Поиска по OEM-номеру в API нет** — соответствие OEM/TecDoc → SKU даётся отдельным файлом каталога. Есть альтернатива — ежедневные CSV.
- Страны: «Польша и за рубежом». **Для Финляндии непригодно, пока нет договора с Inter Cars** (в FI филиала не найдено). Вывод: не первый приоритет.

## 3. Varaosahaku.fi — шаблоны deep-link [проверено по маршрутам Angular-приложения]

- По OEM-номеру: **`https://www.varaosahaku.fi/fi-fi/OEM/<OEM>`** (без пробелов и дефисов, сайт сам рекомендует так)
- Полнотекстовый: `https://www.varaosahaku.fi/fi-fi/pb/Hae/Autonosat/s15/FTS?query=<текст>`

- По рег. номеру: страница `https://www.varaosahaku.fi/fi-fi/pb/Hae/Autonosat/s2/Regnr` (номер вводится в форму; прямого параметра не нашёл)

## 4. Traficom: номер → VIN/модель

- **Открытые данные** («Ajoneuvojen avoin data», avoindata.suomi.fi, CSV/ZIP, CC BY 4.0, ~5,3 млн строк) **не содержат рег. номер и VIN** — Traficom считает их персональными данными. Есть только 10 знаков VIN без серийной части + марка/модель/техданные. Для поиска по номеру непригодно.
- Поиск по номеру — только по лицензии: договор и разрешение Traficom + договор с TietoEvry (передача данных), либо через коммерческих посредников (напр. Dun & Bradstreet), которые оформляют лицензию за клиента. Контакт: tietojenluovutus@traficom.fi. Дорого и бюрократично; в 2025 был инцидент со злоупотреблением доступом → проверяют строго.
- Вывод: **не нужно**. Хранить VIN/номер шасси в карточке машины RAHTIS (перевозчик вводит один раз, VIN есть в техпаспорте). Номер шасси нужен для поиска у DAF/TAVO/дилеров.

## 5. TecDoc / TecCom

- TecDoc (TecAlliance) — лицензия напрямую у TecAlliance, без публичной цены, ежегодные переговоры; SOAP/REST. Говорит «что подходит», но **не цены и не наличие** (это TecCom или прайс-фиды поставщиков). Кроссы OE→аналог неполные. Отдельно ли лицензируется грузовой сегмент — [не проверено].
- Для MVP избыточно. Может иметь смысл позже, если будем делать собственный подбор аналогов.

## 6. Условия использования / парсинг

- varaosahaku.fi: robots `Disallow: /` для всех и `ai-input=no, search=no` — **парсинг запрещён**.
- raskassarja247.fi: robots `Disallow: /fin/haku` — поиск не индексировать/не парсить.
- truck1.fi: `Disallow: /*?` (запросы с параметрами).
- Остальные — закрыты логином или Cloudflare. **Итого: «вытаскивать» цены к себе можно только по договору/API. Без договора — только deep-link (пользователь сам открывает сайт).**

## 7. Рекомендация: дизайн «быстрого поиска»

Перевозчик вводит **номер детали (OEM)** и/или выбирает машину (марка/модель/VIN из карточки), коротко описывает деталь, ставит срочность. Дальше три слоя:

**Слой A — мгновенно через API (сейчас: ничего).**
Ни у одного финского поставщика публичного API нет. Inter Cars IC API есть, но в Финляндии Inter Cars не работает. Действие: написать в Raskassarja, TAVO, Skuba с предложением партнёрства (прайс/наличие по API или ежедневный CSV-фид в обмен на поток заявок). Первый, кто даст фид, попадает в слой A с карточками «цена / наличие / срок».

**Слой B — deep-link (делаем сразу, без договоров).** Кнопки «Открыть результаты» с подставленным номером:
- Raskassarja 24/7: `https://raskassarja247.fi/fin/haku?s={OEM}` (перепроверить после запуска нового магазина 29.10.2026)
- Varaosahaku (б/у): `https://www.varaosahaku.fi/fi-fi/OEM/{OEM}` и `…/s15/FTS?query={текст}`
- Ссылки на кабинеты без подстановки: Skuba EMS, TAVO/protruck.fi, DAF parts.daf.com, MAN PartsBase/partslink24, Mercedes B2B Connect — «если у вас есть аккаунт». Под каждую марку показывать свой портал.
- Номер копировать в буфер одним нажатием (для сайтов без URL-параметра).
- Шаблоны держать в таблице БД (`supplier_links`: шаблон, марки, активен), а не в коде — сайты будут меняться. Еженедельная автопроверка «шаблон отдаёт 200».

**Слой C — RFQ (главная ценность, делаем сразу).** Одна заявка → e-mail/форма 3–10 поставщикам: OEM, марка/модель/год, VIN/шасси, фото, город доставки, срок. Ответ поставщик вносит по ссылке без регистрации (цена, наличие, срок, новая/б/у/аналог). Перевозчик видит 2–4 предложения в одной карточке. Адресаты:
- новые: Skuba (info@skuba.fi), TAVO, Raskassarja (или их tuotekysely), дилеры марки (Volvo, Scania, MAN, DAF, Mercedes, Renault, Iveco — контакты из dealer-locator по городу);
- б/у: разборки грузовиков (Kauppilan Autohajottamo, Osamyynti Trucks и др. — собрать список вручную), плюс ссылка на varaosahaku create-inquiry.
- Договориться с поставщиками заранее (согласие на получение заявок), иначе письма будут уходить в спам — и это важно для GDPR/репутации.

**Порядок:** (1) RFQ + deep-links (1–2 недели); (2) переговоры о фиде с Raskassarja/TAVO/Skuba; (3) только потом — API-слой.
