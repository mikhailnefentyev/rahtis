# Приложение водителя — дизайн-обязательства

Правила, которым следует каждый экран `src/app/[locale]/driver/`. Собраны 27.09.2026 из
[Mobile Taste](https://github.com/draftbit/mobile-taste-skill) (Draftbit; сам навык — под
React Native, сюда перенесено то, что не зависит от платформы) и чек-листа `ui-ux-pro-max`,
поверх токенов проекта (`globals.css`, `src/components/ui/tone.ts`).

## Кто и где

- Водитель грузовика в кабине и на площадке порта: одна рука, часто в перчатке, яркое солнце
  или ночь, связь пропадает.
- Язык — телефона водителя (10 языков). Длинные слова (lt, pl, fi) не должны ломать кнопки.
- PWA, светлая тема сайта. Тёмный — только экран-тахограф тренажёра (токены `night-*`).

## Жёсткие нижние границы

| Что | Правило |
|---|---|
| Цель нажатия | не меньше 44 px по высоте; главное действие экрана — 56 px (`h-14`) |
| Текст | основной 15–17 px; вспомогательный не меньше 13 px; `text-xs` не использовать |
| Контраст | текст на светлом — `ink`, `ink-muted`, `ink-faint`; `ink-dim` только для неактивного, не для читаемого |
| Отклик | каждое нажатие затемняет цель (`[data-app='driver'] … :active` в `globals.css`) |
| Движение | только `motion-safe:`; сдвигов и масштабирования при нажатии нет |
| Медленная сеть | у каждого сегмента есть `loading.tsx` (`DriverSkeleton`) |
| Без связи | действие встаёт в очередь (`OutboxProvider`), экран идёт дальше |

## Композиция

- Одно главное действие на экран, залито акцентом, во всю ширину. Второстепенные — обводкой.
- Разрушающее действие (закончить день, удалить) — красной обводкой, не заливкой: заливка
  рядом с обычной кнопкой ловит промах перчаткой.
- Нижняя навигация — ровно пять пунктов, текстом. Новые разделы — плиткой на главной или
  строкой в профиле, а не шестым пунктом.
- Шапка экрана говорит, где водитель: заголовок раздела и данные дела (номер рейса, номер
  машины). Приветствий нет.
- Поля формы — с видимой подписью над полем; подсказка внутри поля подписью не считается.
  У имени и телефона — `autoComplete`.

## Иконки и знаки

- Эмодзи в интерфейсе нет. Нужна иконка — встроенный SVG, `stroke="currentColor"`, 20 px,
  `aria-hidden`, рядом всегда текст.
- `✓`, `←`, `›` — типографские знаки, допустимы как часть текста.

## Аудит 27.09.2026 (статический проход)

Живой проход ограничен: без приглашения доступны только экран входа и тренажёр. Рабочие
экраны проверены по коду.

Исправлено:
- эмодзи 📷 на кнопке съёмки → SVG-иконка;
- отметка повреждения при осмотре: чекбокс 20 px → плашка 48 px с состоянием;
- имя подписавшего: подсказка внутри поля → видимая подпись, `autoComplete="name"`;
- «Закончить день» — красная заливка → красная обводка;
- пройденные точки рейса: `ink-dim` → `ink-faint` (читаемо на солнце);
- приветствие на главной → номер машины;
- стрелки месяцев в заработке: подпись для экранного диктора «‹» → название месяца;
- фильтры карты и переключатели тренажёра: 40 px → 44 px;
- мелкий текст 12 px в осмотре и полосе смены → 13 px;
- отклик на нажатие во всём приложении и `loading.tsx` для медленной сети.
