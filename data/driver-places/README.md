# Точки для водителя: заправки, стоянки, душ, сервис

Справочник для вкладки «Kartta» в приложении водителя. Кабинетам
перевозчика и заказчика он не виден (RLS в `driver_places`).

- `source/*.xlsx` — исходное исследование по FI, SE, NO, DK от 22.09.2026,
  по-русски. Хранится для справки; приложение его не читает.
- `source/fi-vt11-25.xlsx` — дополнение от 24.09.2026: заправки, стоянки и
  душ на трассах VT11–VT25 (27 станций; 20 новых, 7 уже были и дополнены).
  Адреса и координаты станций St1 и Neste взяты с их официальных карточек,
  ABC — геокодированием по названию. Ремонт в Kyyjärvi и Jämsä помечен
  `warning` со сроком: после срока снять пометку и запись `state`.
- `source/Грузовые стоянки Европы — обогащённая база.csv` — европейский
  набор стоянок для фур (около 19 700 точек; с 21.10.2026 заменил
  `truckParkingLocationsEurope_…_v02.csv` с теми же номерами строк). Из
  него 21.10.2026 добавлены Эстония, Латвия, Литва, Польша и Германия:
  3 369 точек (EE 67, LV 74, LT 146, PL 809, DE 2 273). Отбор: все точки
  Прибалтики; в Польше и Германии — с высокой достоверностью и со
  средней в пределах 5 км от маршрутов из финских паромных портов
  (Via Baltica, дороги к портам, автобаны от Травемюнде, Ростока и Киля);
  дубли ближе 150 м сливаются. Название — тип площадки (или сеть
  заправки) и ближайший населённый пункт по GeoNames. Услуги по
  OpenStreetMap (заправка, дизель для грузовиков, AdBlue, душ, часы,
  сеть) в наборе есть только у части стран — из наших это Эстония
  (46 точек дополнены); у LV, LT, PL и DE услуги не указаны и не
  проверены. id вида `de-tp-<id строки CSV>`.
- `places.json` — источник правды: 3 893 точки с координатами и текстами
  на финском и английском. Правки вносятся здесь.

Загрузка в базу (служебный ключ из `.env.local`, повторный запуск
обновляет точки по `id` и удаляет исчезнувшие):

    npm run places:import

Как собирался `places.json`: строки таблиц объединены в точки (одна
станция на нескольких листах — одна точка), координаты получены из
адресов через TomTom и проверены на расстояние до населённого пункта и
совпадение названия. Где проверка не прошла — точка стоит в центре
населённого пункта с `approx: true`, и навигация ищет её по названию
(в основном норвежские площадки døgnhvileplass на севере).

Поля: `kinds` — FUEL, PARKING, SHOWER, SERVICE; `free`, `secured`,
`sauna`, `warning` — для фильтров и меток; `details` — строки с ключом
`k` (price, security, facilities, capacity, notes, state) на двух языках.
